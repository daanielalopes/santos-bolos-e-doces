# Santos Bolos e Doces 🍰

Site institucional de uma confeitaria fictícia, desenvolvido com **HTML e CSS**. Apresenta os bolos e doces, sabores e massas por meio de uma galeria de imagens.

## 📋 Sobre

Página web estática que serve de vitrine para uma confeitaria: seções com destaques de produtos, variedade de sabores e tipos de massa.

## 🗂️ Estrutura

```
.
├── index.html     # página principal
├── style.css      # estilos
└── img/           # fotos de bolos, doces, sabores e massas
```

## ▶️ Como visualizar

Abra o arquivo `index.html` no navegador — não requer instalação.

## 🛠️ Tecnologias

- HTML
- CSS
